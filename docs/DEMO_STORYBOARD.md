# Demo storyboard (UI segments)

Companion to `DEMO_PLAN.md` (three minutes). Frames in `docs/demo/screens/` (regenerated for checkpoint 3) are
generated by `DEMO_SCREENS=1 npm run test:e2e -- --grep storyboard` from
`apps/web`, using responses recorded from Codex's backend for the **synthetic
training scene**. Every frame shows the SYNTHETIC badge and banner. Replace the
satellite segments with a real AOI recording once Codex's credentialed run
exists; do not narrate these frames as a real flood.

One decision carries the demo: *a settlement may lose road access. Which edge
causes that, what is the evidence, does an alternate route remain, and can I
hand a cited brief to someone?*

## Recording notes

- Start from a clean browser profile; save the offline package before turning
  the network off. DevTools offline or airplane mode both work.
- Keep the evidence inspector open while explaining a claim. Avoid scrolling
  through method notes on camera; they're collapsed under *Method notes*.
- Do not show the simulation as a capability of real drones. Say "simulation".
- Attributions are in the map corner and in the brief footer.
